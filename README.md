# Thomas Connally

Founder of [Perseus Computing LLC](https://perseuscomputing.com) in Austin, Texas. I build open-source infrastructure for AI agents that runs on your own hardware.

Current work is **Telarch**, three libraries maintained at [Perseus-Computing-LLC](https://github.com/Perseus-Computing-LLC):

- [Harpe](https://github.com/Perseus-Computing-LLC/harpe) keeps each model call under a token ceiling.
- [Kibisis](https://github.com/Perseus-Computing-LLC/kibisis) is local agent memory with one writer per resource.
- [Argus](https://github.com/Perseus-Computing-LLC/argus) is a SHA-256 hash chain of agent actions. Editing a past entry breaks every later one.

All three are alpha releases under the MIT License.
